## 🔧 Customization

### Change Profile Photo
Edit `index.html` and update the profile image path:
```html
<img src="path-to-your-image.jpg" alt="Deepak portrait" />
```

### Update Project Links
Modify the project card href in `index.html`:
```html
<a href="your-project-link" class="project-card">
```

### Modify Colors
Edit CSS variables in `styles.css`:
```css
:root {
  --bg: #f3f0ea;
  --panel: #ffffff;
  --primary: #1a1a1a;
  /* ... more colors ... */
}
```
