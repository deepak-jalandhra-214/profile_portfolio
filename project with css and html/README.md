# Amazon Display Clone Project

A static Amazon-inspired landing page built with HTML and CSS.

## Overview

This project recreates the look and feel of an Amazon homepage section, including:
- top navigation bar with logo, search input, language selector, account, orders, and cart
- category navigation menu
- hero section and promotional product cards
- footer with multi-column links

## Files

- `amazon-clone.html` — main HTML page for the clone layout
- `amazon-clone.css` — page styling and responsive layout
- `product-images/` — image assets used for the product cards and logo
- `README.md` — project documentation

## How to use

1. Open `amazon-clone.html` in your web browser.
2. Make sure the `amazon-clone.css` file is in the same folder so the styles load correctly.
3. Keep the `product-images/` folder next to the HTML file for the page images.

## Notes

- This is a static front-end demo only; there is no backend or shopping functionality.
- The page uses Font Awesome icons from the CDN for the navigation icons.
- You can customize the text, images, and styles by editing `amazon-clone.html` and `amazon-clone.css`.
